# Code of Conduct

## Our Standard

We want EffecCol to be a respectful, practical, and welcoming open-source project.

Examples of positive behavior include:

- being respectful and constructive
- focusing on user problems and evidence
- giving actionable feedback
- assuming good intent while staying honest

Examples of unacceptable behavior include:

- harassment or personal attacks
- bad-faith participation
- publishing private information without permission
- dismissive or hostile communication

## Scope

This code of conduct applies in project spaces such as issues, pull requests, discussions, and other contribution channels.

## Enforcement

Project maintainers may remove, edit, or reject contributions or comments that do not align with this code of conduct.
