# Contributing to EffecCol

Thanks for your interest in EffecCol.

EffecCol is still an early-stage project, so the most helpful contributions are usually practical improvements to capture quality, setup clarity, and release readiness.

## Good First Contribution Areas

- Article extraction on tricky sites
- Image filtering and image download reliability
- Error handling and onboarding clarity
- Documentation improvements
- Packaging and release workflow

## Before You Start

1. Read [README.md](./README.md) first.
2. Check whether the issue already exists.
3. If the change affects behavior, describe the user problem it solves.

## Pull Request Guidelines

Please keep pull requests focused and small when possible.

Helpful PRs usually include:

- what problem is being solved
- what changed
- how it was tested
- any limitations or known follow-up work

## Testing

At this stage, most verification is still manual.

Useful manual checks include:

- settings page loads correctly
- clicking the extension on an article page triggers capture
- Obsidian note is created under `EffecCol/`
- clipboard card is copied
- low-value page warning still appears when expected

## Communication

If you are unsure whether a change fits the project direction, open an issue first and describe the user scenario you want to improve.
