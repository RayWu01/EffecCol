# Security Policy

## Supported Status

EffecCol is currently an early-stage open-source project and does not yet have a formal long-term support policy.

Please assume the latest main branch is the best-supported version for now.

## Reporting a Vulnerability

If you discover a security issue, please avoid posting full exploit details in a public issue right away.

Instead, share:

- a short summary of the problem
- affected component
- reproduction steps
- potential impact

If you do not have a private reporting channel yet, open a minimal public issue without sensitive exploit details and note that you are reporting a security concern.

## Current Security Notes

EffecCol uses a local Obsidian plugin and local browser extension communication. The project already includes a local pairing token for save requests, but the security model is still evolving and should be reviewed further before broad public release.
